# React Counter

ReactのuseStateを使用したカウンターアプリです。

## 機能
- カウントアップ
- カウントダウン
- カウントのリセット

## 使用技術
- React
- JavaScript (JSX)
- CSS
- Vite

## 学習内容
- Reactコンポーネント
- useStateによる状態管理
- onClickイベントの処理
- CSSの読み込み

## 実行方法

```bash
npm install
npm run dev
```

## ビルド方法

```bash
npm run build
```
